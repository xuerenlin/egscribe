# 二、视图操作（必备快捷键）

|操作|快捷键/方法|
|--|--|
|旋转视图|按住 鼠标中键 + 拖动|
|平移视图|Shift + 鼠标中键 + 拖动|
|缩放视图|滚动鼠标滚轮|
|切换正交/透视视图|小键盘5|
|切换视图（前/右/顶等）|小键盘1/3/7（需开启NumLock）|
|聚焦选中物体|小键盘.|

# 三、基础建模操作

{{SPACE_LINE}}

|操作|快捷键/方法|说明|
|--|--|--|
|移动|G + 鼠标拖动|按 X/Y/Z 可锁定轴向|
|旋转rotate|R + 鼠标拖动|同上|
|缩放scale|S + 鼠标拖动|同上|
|精确输入|操作后直接输入数值（如 G Z 2 沿Z轴移动2单位）||

# 四、常用快捷键速查

|功能|快捷键|
|--|--|
|新建物体|Shift + A|
|删除物体|X 或 Delete|
|复制物体double|Shift + D|
|合并物体|Ctrl + J|
|撤销/重做|Ctrl + Z / Ctrl + Shift + Z|
|渲染当前视图|F12|
|保存文件|Ctrl + S|
|进入编辑模式|按 Tab，选择顶点/边/面修改形状|
